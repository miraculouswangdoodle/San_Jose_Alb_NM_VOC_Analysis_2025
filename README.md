# San_Jose_Alb_NM_VOC_Analysis_2025
This is the repository for data and code related to Jaimie Ritchie's Thesis on Air Quality, Volatile Organic Compounds (VOCs) as measured at the San Jose Trailer site in Albuquerque, NM. The paper is in [Journal] as What Pollutants Are in My Air: Source Characterization and Temporal Variability of Outdoor Volatile Organic Compound Exposure in Albuquerque, New Mexico, USA.

Please see the "City Memo_final_SOP.docx" file for information on how to use the files in this directory to process raw data from the GC-FID at the San Jose Trailer site in Albuquerque, NM.
