# San_Jose_Alb_NM_VOC_Analysis_2025
This is the repository for data and code related to Jaimie Ritchie's Thesis on Air Quality, Volatile Organic Compounds (VOCs) as measured at the San Jose Trailer site in Albuquerque, NM. The paper is in [Journal] as [Title].
